# Pokédex CLI

A command-line Pokédex built with TypeScript and Node.js as part of a programming course.

The project uses the [PokéAPI](https://pokeapi.co/) to retrieve Pokémon and location data while practicing core backend development concepts.

## Features

- Fetch data from a REST API
- Cache API responses to reduce unnecessary requests
- Explore locations and discover Pokémon
- Catch Pokémon using a probability-based mechanic
- Inspect captured Pokémon and their stats
- Manage a local Pokédex

## Technologies

- TypeScript
- Node.js
- REST APIs
- Vitest

## Purpose

This project is an educational exercise focused on asynchronous programming, HTTP requests, caching, type safety, and application state management.
